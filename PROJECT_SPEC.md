# Project specification

## Goal
Demonstrate a transparent corridor-planning workflow for a fictional emergency-response scenario.

## Workflow
1. Choose origin, destination and traffic scenario.
2. Find a shortest path on a weighted graph using Dijkstra's algorithm.
3. Compare assumed baseline and coordinated signal delays.
4. Show the route, illustrative timing comparison, responder summary and event log.

## Implemented
Plain HTML/CSS/JavaScript; seven fictional junctions (A–G); route visualization; normal/busy timing assumptions; input validation; reset and copy summary.

## Not implemented
Live maps/GPS, traffic feeds, real AI/ML prediction, emergency dispatch, traffic-controller integration, field trials or safety certification.
